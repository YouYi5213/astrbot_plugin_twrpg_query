# astrbot_plugin_twrpg_query

世界RPG（TWRPG）离线查询 AstrBot 插件。

更新记录见 [CHANGELOG.md](CHANGELOG.md)。

## 用法

在群聊或私聊中发送（无需 `/` 前缀）：

```
世界 洞悉·真理之瞳
界 太阳石
世界 世界破坏者
世界世界破坏者
英雄 追星剑圣
技能 升龙击
世界材料 世界破坏者
世界材料 太阳石 x5
世界图鉴 武器 四大
世界图鉴 材料 第2页
世界在线
世界目标
魔兽房间
魔兽房间 全部
魔兽房间 守护雅典娜
魔兽房间 更新目录
```

插件会以图片卡片展示以下信息（有数据才显示对应区块）：

**物品查询**

- **佩戴限定**：可佩戴英雄头像（与 QuickSearch 一致）
- **专属效果**：英雄头像 + 专属技能改动说明
- **属性**：GamePanel 金色边框 + War3 彩色描述与被动
- **合成方式**：合成所需材料（含图标）
- **可合成物品**：以该物品为材料的合成目标（含图标）
- **来源**：BOSS 掉落（含 BOSS 图标）

**英雄查询**

- 英雄头像、职业名、角色名
- 全部技能：图标 + 热键（如 `[Q]`）+ 描述

**技能查询**

- 技能图标、名称、热键、描述
- 所属英雄（含头像）

**材料缺料统计**（`世界材料 <物品名> [xN]`）

- 递归展开目标物品的合成配方，列出所有缺口材料及数量
- 每个缺口材料附带 BOSS 掉落来源与掉率（按阶段从高到低）
- 配方中的「任选其一」材料单独列为可选材料
- 绑定云存档后自动扣除携带 / 背包 / 仓库里的现有库存；未绑定时只按配方展开并提示

**图鉴分类浏览**（`世界图鉴 [分类] [阶段] [关键词] [第N页]`）

- 分类：`武器` / `衣服` / `头盔` / `饰品` / `翅膀` / `材料` / `其他` / `全部`，也支持 `剑`、`戒指`、`素材` 等别名
- 阶段：`野外` `粉末` `小四` `四大` `主龙` `白怨火水` `君主` `爵土马判` `大天使`（或用数字 1–9）
- 关键词：如 `世界图鉴 武器 剑`、`世界图鉴 武器 四大 第2页`

**目标缺料汇总**（`世界目标`）

- 读取读档器为当前存档设置的收集目标（云端 `/api/item-goals`，与读档器共用同一份，**只读不写**）
- 一次展开全部目标，列出每个目标还差多少种材料，再给出合并缺口与掉落来源
- 同一材料被多个目标需要时只统计一次总量，库存按目标依赖顺序依次扣减
- 还没在读档器里加过目标时，会提示去读档器里右键物品「加入收集目标」

**在线房间**（`魔兽房间`）

- 默认查世界RPG（mapId 2310），只列出**现在能直接加入**的房间（属性 `-`），按人数从多到少排，**带密码的房间排在最后**
- 以**图片卡片**展示，排版贴近 KK 平台房间列表：
  - 顶部：地图图标、地图名、标签（组队合作 / 冒险等）、`War3 · 分类 · 版本`、热度与评分
  - 表格：房间号 / 房间名称 / 模式 / 地图等级 / 房间人数 / 房间属性
  - VIP 房间红色房名 + `V` 标，密码房带锁图标；等级限制每行都显示，无限制为 `-`
- `魔兽房间 全部` — 连同「游戏中」的房间一起列出；**观战房间始终隐藏**
- `魔兽房间 <地图ID或名称>` — 查别的地图，如 `魔兽房间 2310`、`魔兽房间 守护雅典娜`
  - 地图名走本地缓存的地图目录做模糊匹配：完全同名 > 前缀 > 包含
  - 名字唯一命中就直接查；命中多个相似地图时列出候选（地图名 + ID），用 ID 再查即可
  - 官方没有可用的地图名搜索接口，地图目录**不会自动拉取**：
    管理员发送 `魔兽房间 更新目录` 手动更新一次（约 40 个请求，1~2 秒），
    结果保存到 `kk_room/map_index.json`，之后一直复用
  - 还没更新过目录时，按名字查会提示先更新；按地图 ID 查询不受影响
  - 名字里带「测试」或接口标记为测试的地图不会进入目录，也不会出现在候选里
  - 世界RPG（2310）和守护小天使（197239）不参与官方目录，索引里会按 mapId 自动补上
- 地图图标只在**主动查询某张地图时**下载一次，缓存在 `cards/map_logos/<mapId>.png`，
  之后一直复用，不会重复下载
- 数据来自 KK 官方接口，需要 Windows 端（能登录 KK 平台的那台机器）把 web token 同步到
  插件数据目录的 `kk_room/token.json`；token 过期后会提示稍后重试
- 同一份房间数据缓存 10 秒，群聊里连续查询不会把上游当压测目标

## 云存档（可选）

在 WebUI 插件配置中开启 **「启用云存档绑定功能」** 后，可使用以下指令（无需 `/` 前缀）：

| 指令 | 说明 |
|------|------|
| `世界登录 用户名 密码` | 私聊绑定云存档账号 |
| `世界解绑` | 解除绑定 |
| `世界存档` | 云端存档列表 |
| `世界切换 <序号>` | 切换主存档 |
| `世界档案` | 角色信息 |
| `世界背包` / `世界仓库` / `世界携带` | 物品列表 |
| `世界在线` | 当前在线人数与自己的累计在线时长 |
| `世界目标` | 汇总读档器里为当前存档设置的目标缺料 |
| `世界云帮助` | 云存档帮助 |

> `世界材料 <物品名>` 在绑定云存档后会自动读取主存档库存，未绑定时仍可统计配方缺口。
>
> `世界在线` 统计的是**5 分钟内活跃的读档器会话数**（同一账号多端登录分别计数），
> 需要先 `世界登录` 才能查询。
>
> `世界目标` 读取读档器为该存档设置的收集目标（与读档器共用云端同一份列表，插件只读不写）：
> 在桌面上把物品加为收集目标，机器人这边发一句就能看到所有目标的合并缺口与掉落来源。
> 目标支持多份（同一物品加两次即需要两件），库存会按目标依次扣减。

关闭配置开关后，上述指令**不生效**，离线物品/英雄/技能/BOSS 查询不受影响。

若已安装独立的 `astrbot_plugin_twrpg_cloud`，建议卸载以免指令重复。

## 配置

WebUI → 插件管理 → 世界RPG 查询 → 配置：

| 配置项 | 说明 |
|--------|------|
| `cloud_save_enabled` | 是否启用云存档绑定（默认开启） |
| `cloud_base_urls` | 云服务器地址，每行一个 |
| `cloud_login_private_only` | 登录是否仅允许私聊 |
| `kk_room_enabled` | 是否启用 `世界房间`（默认开启） |
| `kk_room_token_path` | 房间 token 路径，留空 = 插件数据目录/`kk_room/token.json` |

## 安装

```bash
cd AstrBot/data/plugins
git clone <本仓库地址> astrbot_plugin_twrpg_query
```

依赖：`Pillow`、`httpx`（安装插件时自动安装）

## 数据

插件自带 `data/twrpg_query/` 离线数据，来源于 `twrpg_data_tools/extracted_data/`。

更新数据时，将以下文件复制到 `data/twrpg_query/`：

- `items.json`
- `makes.json`
- `drops.json`
- `bosses.json`
- `heros.json`
- `exclusives.json`
- `item_passives.json`（被动/主动描述，可用 `scripts/extract_passives.py` 生成）

英雄技能数据可用 `scripts/extract_hero_skills.py` 从 QuickSearch 重新提取并合并至 `heros.json`。

图标与背景资源可通过 `scripts/sync_assets.py` 从本地 QuickSearch 同步到 `assets/icons/` 与 `assets/items_bg.png`。

## 开发调试

1. 将插件放入 `AstrBot/data/plugins/`
2. 启动 AstrBot
3. WebUI → 插件管理 → 重载插件

运行单元测试（在插件目录内）：

```
python -m pytest -q
```
